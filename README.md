# WorldWeather 🌍⛅

WorldWeather is a simple and modern weather web application that shows live weather information, local time, sunrise and sunset, and weather conditions for major cities around the world. The app is built using HTML, CSS, and vanilla JavaScript, and it uses the OpenWeather API for real-time weather data.

The goal of this project was to build a clean UI weather dashboard that also includes a world clock and multiple city weather cards in one place.

---

## About the Project

This application automatically detects the user's location and displays the current weather, temperature, humidity, wind speed, visibility, pressure, sunrise and sunset time, and a live digital clock for the selected location. Users can also search for any city in the world to view its weather.

In addition to the main weather card, the app also shows weather information and live time for multiple world cities like New York, London, Tokyo, Dubai, Sydney, Paris, Singapore, Kolkata, São Paulo, Cairo, Moscow, and Los Angeles.

The interface is designed with a glassmorphism style and a dark gradient background to make the app look modern and clean.

---

## Features

The application includes the following features:

* Detect current location weather
* Search weather by city name
* Live digital clock based on city timezone
* Sunrise and sunset time
* Humidity, wind speed, visibility, and pressure
* Celsius and Fahrenheit temperature toggle
* World cities weather cards
* Live time for each world city
* Responsive layout for mobile and desktop
* Modern UI design

## How to Run the Project

To run this project locally:

1. Download or clone the repository
2. Open the project folder
3. Open the `index.html` file in your browser
4. Allow location access when prompted
5. The app will load weather data automatically

No installation or build tools are required.

---

## API Configuration

This project uses the OpenWeather API.
You need to replace the API key in the JavaScript file:

```
const API_KEY = 'YOUR_API_KEY';
```

You can get a free API key from:
[https://openweathermap.org/api](https://openweathermap.org/api)
